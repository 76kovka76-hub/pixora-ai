# PIXORA AI

Telegram Mini App для обработки фотографий и подготовки визуалов товаров.

## Текущий статус

Это ранний MVP-каркас, а не опубликованный сервис.

Уже подготовлено:
- интерфейс Mini App на русском языке;
- FastAPI API и SQLite;
- проверка подписи Telegram Mini App `initData` на сервере;
- две бесплатные операции на пользователя;
- три базовые операции с фото: автоулучшение контраста/цвета/резкости, тёплый цвет, чёрно-белый эффект;
- ограничение размера загружаемого файла.

Пока не реализовано:
- полноценное AI-редактирование и удаление объектов;
- генерация пяти слайдов карточки товара;
- Telegram-бот и настройка Menu Button;
- оплата Telegram Stars и продление подписки;
- production-развёртывание, мониторинг и резервные копии.

## Локальный запуск

Нужен Python 3.11 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполни `BOT_TOKEN` токеном Telegram-бота в локальном файле `.env`, затем:

```bash
uvicorn app.main:app --reload
```

Открой `http://127.0.0.1:8000` для проверки интерфейса. Для авторизованных API-запросов Mini App должен быть открыт через Telegram и иметь корректно настроенный бот и HTTPS URL.

## Telegram-бот (webhook)\n\nДобавлен минимальный обработчик `/start`, который отправляет кнопку открытия Mini App. После размещения на HTTPS нужно задать `BOT_TOKEN`, `WEBAPP_URL` и случайный `TELEGRAM_WEBHOOK_SECRET`, затем зарегистрировать webhook через Telegram Bot API по адресу `https://ВАШ-ДОМЕН/api/telegram/webhook`, передав тот же секрет как `secret_token`. Webhook пока не зарегистрирован: для этого нужны токен бота и публичный HTTPS-домен.\n\n## Переменные окружения

- `BOT_TOKEN` — токен бота; не добавлять в GitHub.
- `WEBAPP_URL` — HTTPS-адрес Mini App после размещения.
- `DATABASE_PATH` — путь к SQLite базе.
- `MAX_UPLOAD_MB` — максимальный размер изображения в МБ.

## Важные замечания перед запуском

1. Разместить приложение на HTTPS-хостинге и подключить домен Mini App через BotFather.
2. Убедиться, что SQLite хранится на постоянном диске; для масштабирования перейти на управляемую БД.
3. Проверить лимиты, обработку ошибок, MIME/форматы и защиту от злоупотреблений.
4. Реализовать и протестировать генератор карточек на реальных товарах, не выдумывая характеристики.
5. Подключать платёжный поток Telegram Stars только после проверки актуальных правил Telegram и тестовых платежей.
